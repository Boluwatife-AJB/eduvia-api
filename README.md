# Eduvia API

Eduvia is a production-ready, open-source multi-tenant school management platform API built for African schools and institutions worldwide. Designed with a modular monolith architecture using NestJS and TypeScript, it provides a comprehensive backend for managing every stakeholder in a school; students, teachers, parents, non-teaching staff and administrators, each with role-scoped access to the features that matter to them.  
Built with scalability, security and developer experience in mind, Eduvia handles academic session management, subject and class configuration, timetabling, assessments, results, staff payroll, fee payments, real-time notifications, attendance tracking, counseling, library management and more all under one roof with full multi-tenancy isolation between schools.
